시범 운영

설계부터 검증까지

프로젝트에 적용합니다.

하네스는 개발 언어와 실행 환경을 정하고, 화면·기능 설계와 테스트를 돕습니다. 체커는 개발 중과 완료 후 보안 점검을 지원합니다.

현재 설치 상태

확인 중

승인된 설치 파일 정보를 불러오는 중입니다.

1

설치 파일 확인

승인된 Windows 설치 파일과 서명 정보를 확인합니다.

설치 파일 준비 중

공식 설치 파일이 등록되면 여기에서 내려받습니다.

2

프로젝트에 적용

Codex 또는 Claude Code를 선택하고 개발 언어와 환경을 정합니다.

설치·사용 방법

개인정보와 비밀값은 프롬프트나 증적에 입력하지 않습니다.

3

개발과 검증

화면과 기능을 확인한 뒤 구현하고, 테스트와 체커 점검 결과를 확인합니다.

GitHub 저장소

최종 이관·배포 전에는 사람 검토가 필요합니다.

시범 운영 안내

이 페이지는 설치 파일을 자동 실행하지 않습니다. 공식 Windows 설치 파일, 서명 해시, 릴리스 노트가 등록된 경우에만 다운로드를 제공합니다.
