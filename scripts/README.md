# 실행기 구현 계약

이 폴더에는 다음 단계에서 `gg` 실행기를 구현한다. 현재는 설계만 있으며, 명령이 동작한다고 주장하지 않는다.

현재 실행 가능한 범위는 `validate-design.ps1`뿐이다. 이 스크립트는 공통 정책·기관 프로파일·Codex/Claude 어댑터 템플릿·화면 중심 질문 정책의 기본 일관성을 검사한다.

- Windows 우선: `gg.ps1` 또는 코드서명된 로컬 에이전트가 명령 진입점이 된다.
- 공통 로직: Node.js 또는 Python 중 승인 트랙과 배포 패키지 구조에 맞는 하나를 선택하되, 구현 언어 정책 검증 대상에 포함한다.
- `gg init`, `gg doctor`, `gg verify`를 최소 실행 단위로 먼저 구현한다.
- 모든 상태 변경은 로그·백업·재검증·실패 코드·다음 행동을 남긴다.

## 시험운영 E2E

`node scripts/pilot-e2e.mjs` (또는 `npm run pilot:e2e`) 는 임시 폴더에서만 실제 CLI 와 정책 엔진으로 언어 정책·테스트 축·패키지 설치 정책·지원 도구 목록을 확인하고 한국어 표를 출력한다. 실패가 있으면 0 이 아닌 코드로 끝난다. 포털 판정 동일성 등 하네스 혼자 확인할 수 없는 항목은 통과로 적지 않고 포털 측 테스트 이름만 적는다.
